# 2023 SRS Machine Learning Course

## Overview
This repository contains practical exercises, algorithm implementations, and Jupyter notebooks developed during the 2023 SRS Machine Learning course. It covers the end-to-end data science lifecycle, from data preprocessing and exploratory analysis to model training, hyperparameter tuning, and evaluation.

## Features
* Implementations of core classification, regression, and clustering algorithms.
* Data preprocessing pipelines including missing value handling, scaling, and encoding.
* Model evaluation using cross-validation, ROC-AUC curves, and error analysis metrics.
* Hands-on notebook exercises structured for self-paced review.

## Technologies
* Programming Language: Python
* Tools & Libraries: Jupyter Notebook, Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

## Project Structure
